## Data Source

The `SR2025.csv` file is automatically downloaded from the City of Toronto's Open Data Portal when you run `analysis.py`.

**Source:** https://open.toronto.ca/dataset/311-service-requests/
**Package ID:** 2e54bc0e-4399-4076-b717-351df5918ae7
**Format:** ZIP containing CSV
**Size:** ~67 MB (464,080 rows)

If the file is not present, the script will download it automatically and save it here.
